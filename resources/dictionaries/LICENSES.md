# 许可证与署名索引

本目录中的样例不是本项目新创作的词典数据；其许可随各来源而定。`sources.json` 是唯一机器可读清单，下面提供人工可读的最小归因索引。

| `source_id` | 许可证/条件 | 必须或建议保留的归因 |
| --- | --- | --- |
| `open_english_wordnet` | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | “Open English Wordnet Community, CC BY 4.0”，附项目页与许可证链接，并说明已做的转换。 |
| `ecdict` | [MIT（仓库声明）](https://github.com/skywind3000/ECDICT/blob/master/LICENSE) | 保留上游 MIT 版权与许可文本；公开再分发前复核其多源内容的血缘。 |
| `cmudict` | [CMUdict LICENSE](https://github.com/cmusphinx/cmudict/blob/master/LICENSE) / BSD 风格 | 使用或再分发说明中确认 Carnegie Mellon University / CMUdict 来源。 |
| `wikidata_lexemes` | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) | 法律上不要求署名；建议标示 “Wikidata Lexemes (CC0)” 以保留来源透明度。单独媒体文件不在此项覆盖范围。 |
| `english_wiktionary` | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) + [GFDL](https://www.gnu.org/licenses/fdl-1.3.html) | 显著归属、条目/修订或透明副本链接、许可证链接和 ShareAlike/GFDL 合规。 |
| `kaikki_wiktextract` | 处理工具不改变 Wiktionary 内容许可 | 同 `english_wiktionary`；同时标示 Kaikki/Wiktextract 为抽取通道。 |
| `princeton_wordnet_3_0` | [WordNet 3.0 license](https://wordnet.princeton.edu/license-and-commercial-use) | 在所有副本/修改中保留规定版权、声明与免责声明；不得将 Princeton 名称用于宣传。 |

不要把本文件当作对上游完整许可证文本的替代。正式导入时应将对应版本的许可证副本与 release metadata 一起归档到数据存储。
